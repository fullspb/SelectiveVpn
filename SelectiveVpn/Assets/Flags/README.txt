Country flag assets for SelectiveVPN

Downloaded on 2026-11-13 from Flagpedia.net / FlagCDN:
https://flagpedia.net/download/api
https://flagcdn.com/w80/{country-code}.png
https://flagcdn.com/{language}/codes.json

The official Flagpedia API documentation describes the service as free and
supports programmatic downloading of flag images for use in projects.
Flag images are based on vector files from Wikimedia Commons.
Source and attribution: https://flagpedia.net

PNG images retain their original aspect ratios at a width of 80 pixels.
names.json contains localized country names for English, Russian, Spanish,
Portuguese and Chinese, using the same codes as the bundled PNG images.

Country flag images are bundled for offline rendering; displaying a flag does
not require downloading an image when the application runs.
